# MekBitsHitStats

A World of Warcraft 3.3.5a addon that adds hit chance from talents (and the Draenei's Heroic Presence) to the
character sheet. The 3.3.5a client only shows hit from rating there: talent hit works in combat but is invisible.
Talent hit on the character sheet arrived with patch 4.0.1 (`GetHitModifier()`, `GetSpellHitModifier()`), which
3.3.5a does not have.

**Cosmetic only.** The addon reads talents, gear and rating in the client and computes a number. It sends nothing to
the server and does not change combat. If the number is wrong, only the display is wrong.

## What it shows

The character sheet's **Hit** field for **melee**, **ranged** and **spell** shows the **total hit chance in
percent**: rating (converted by the client) + talents + racial. The field's tooltip keeps Blizzard's text and adds a
breakdown:

```
MekBits Hit Stats
Total hit chance: 13.00%
  Rating: 10.00%  (328)
  Talents: +3.00%
    Precision 3/3: +3%
  Other: +1.00%
    Heroic Presence (racial): +1%
  Not counted right now:
    Nerves of Cold Steel 3/3: +3% (needs a one-handed weapon equipped)
  By school:                      (spell only)
    Fire: 16.00%  (+3% Elemental Precision)
```

- **Talents** lists only what the server counts right now. A talent with a weapon requirement (warrior and rogue
  Precision, Nerves of Cold Steel) counts only with a fitting, unbroken weapon in the main hand, off hand or ranged
  slot, as the server does; otherwise it is listed under "Not counted right now".
- **By school** (spell): talents that apply to some schools only (Elemental Precision, Suppression, Balance of Power)
  or to certain spells only (Arcane Focus, Shadow Focus) are not added to the main number but listed per school.
- **Other**: the Draenei's Heroic Presence (+1% melee, ranged and spell). A Draenei in the group gives the same bonus
  within 30 yards; it is counted only if the client shows the aura, otherwise it is shown as a note.

Switch the display with `/mbhs percent` (default: total percent in the field), `/mbhs rating` (the field shows rating
as before, only the tooltip is extended) or `/mbhs off`. The setting is saved in `MekBitsHitStatsDB`.

## Installation

Copy the `MekBitsHitStats` folder (without `test/` if you like) to `World of Warcraft\Interface\AddOns\` and start
the client.

## Talents it knows

Extracted from the server's `Spell.dbc`, `Talent.dbc` and `TalentTab.dbc` (build 12340) and checked against how the
AzerothCore server uses the auras (`SpellAuraEffects.cpp`, `StatSystem.cpp`, `Unit.cpp`, `Object.cpp`,
`Player::HasItemFitToSpellRequirements`). `test/dbc_expected.lua` is generated by `test/tools/extract_hit_talents.py`.
Talents are looked up by tree, row and column, not by name, so every client language works. If a talent's max rank
does not match, it is skipped with a note.

| Class | Talent (spell ids per rank) | Effect (aura) | Applies to |
|---|---|---|---|
| Warrior | Precision (29590, 29591, 29592) | 1/2/3 % (54) | melee + ranged; needs a melee weapon |
| Rogue | Precision (13705, 13832, 13843, 13844, 13845) | 1-5 % (54 + 55) | melee, ranged, spell; needs a weapon |
| Death Knight | Nerves of Cold Steel (49226, 50137, 50138) | 1/2/3 % (54) | melee + ranged; needs a one-handed weapon |
| Death Knight | Virulence (48962, 49567, 49568) | 1/2/3 % (55) | all spells |
| Hunter | Focused Aim (53620, 53621, 53622) | 1/2/3 % (54) | melee + ranged |
| Paladin | Enlightened Judgements (53556, 53557) | 2/4 % (54 + 55) | melee, ranged, spell |
| Shaman | Dual Wield Specialization (30816, 30818, 30819) | 2/4/6 % (54) | melee + ranged, see limitation 1 |
| Shaman | Elemental Precision (30672, 30673, 30674) | 1/2/3 % (199) | Fire, Frost, Nature |
| Mage | Precision (29438, 29439, 29440) | 1/2/3 % (55) | all spells |
| Mage | Arcane Focus (11222, 12839, 12840) | 1/2/3 % (spell modifier) | Arcane spells only |
| Priest | Shadow Focus (15260, 15327, 15328) | 1/2/3 % (spell modifier) | Shadow spells only |
| Warlock | Suppression (18174, 18175, 18176) | 1/2/3 % (199) | Fire and Shadow, see limitation 2 |
| Druid | Balance of Power (33592, 33596) | 2/4 % (199) | all magic schools |
| Draenei | Heroic Presence (28878, 6562) | 1 % (54 + 55) | melee, ranged, spell |

Aura 54 is `SPELL_AURA_MOD_HIT_CHANCE` (the server adds it to melee and ranged), 55 `SPELL_AURA_MOD_SPELL_HIT_CHANCE`,
199 `SPELL_AURA_MOD_INCREASES_SPELL_PCT_TO_HIT` (matched on school mask); the spell modifier is
`SPELL_AURA_ADD_FLAT_MODIFIER` with `SPELLMOD_RESIST_MISS_CHANCE` (only the spells the talent's class mask hits).

Not in 3.3.5a and therefore left out: Surefooted (hunter; only resistance to movement impairment in 3.3.5a) and
Nature's Guidance (not in `Spell.dbc`). Left out on purpose: Survival Tactics (trap and Feign Death resist), Insect
Swarm (reduces the enemy's hit), and target debuffs such as Misery and Improved Faerie Fire.

## Limitations

1. **Dual Wield Specialization** always counts. The spell has no weapon requirement in the DBC and AzerothCore does
   not check for an off hand, so the shaman gets the bonus with one weapon too; the tooltip says so. The talent text
   says "while dual wielding". If the server changes to that, set `DWS_REQUIRES_OFFHAND = true` in `Data.lua`.
2. **Suppression** applies on the server to all Fire and Shadow spells (school mask 36), not only Affliction. The
   tooltip follows the server.
3. **Arcane Focus / Shadow Focus** apply on the server only to the spells their class mask hits; the addon shows them
   for the whole school.
4. The main spell number is hit that applies to every school. School-specific talents are in the tooltip.
5. Hit cap, level difference and the dual wield penalty are not shown, only the bonus breakdown.
6. The data comes from the standard DBC files and the server code. If client patches or a server module change one of
   these talents, the numbers do not match.
7. A fishing pole in hand counts as a two-handed weapon (same `INVTYPE_2HWEAPON`).
8. **Not yet tested in the game client.** See Test.

## Test

Lua 5.1 in an Alpine container, no client needed:

```
bash test/run.sh
```

It runs `luac5.1 -p` on every file, and `test/run.lua` with mocks of the client API (`test/mocks.lua`): it compares
`Data.lua` with the DBC list, computes builds (warrior with Precision and dual wield / broken weapons / 2h, frost mage,
Draenei shaman, hunter, rogue, death knight, paladin, warlock, druid, priest and others) against expected totals, and
exercises the hook on `PaperDollFrame_SetRating`, `/mbhs` and the update on talent and gear changes. To regenerate
the DBC list:

```
py -3 -I test/tools/extract_hit_talents.py <folder with Spell.dbc, Talent.dbc, TalentTab.dbc> --lua test/dbc_expected.lua
```
